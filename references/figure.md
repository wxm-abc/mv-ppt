# `src/figure.js` — 主角手册

一支 270 秒的歌要 85 个镜头。30 个母题平摊下来每个用 2.8 次，**光靠加母题压不住重复感**：
总览图里那些格子仍然长得像同一张图换了颜色。

真正的解法是**画面里有一个人**。同一个地方，她在画面另一处、变了个姿态、离镜头远一点，
就是**另一个镜头**——30 个母题 × 7 种姿态 × 远近 × 左右，组合数远超 85。
这是"素材不重复"和"情节说得通"同时成立的那一个手段。

```

   母题（她在哪儿）          ×          人物状态（她在干什么）
   scenes.js 30 个                       pose / facing / s / x / lamp / ghost
   ────────────────────                  ────────────────────────────────────
   崖边、水面、长廊、草浪…               走、站、坐、跪、伸手、仰望、背影、
                                        提着灯 / 身边还有一个人
```

## 契约

`scene` 块里挂一个 `figure`，**画在母题之后**（她在这地方里，不是贴在这地方前面）：

```json
{ "type": "scene", "motif": "path", "from": "none", "fill": 1, "slot": "main",
  "figure": {
    "at": [0.30, 0.900],
    "s": 0.40,
    "facing": -1,
    "pose": "walk",
    "lamp": true,
    "seed": 0,
    "also": { "at": [0.445, 0.900], "s": 0.39, "facing": -1, "pose": "walk",
              "ghost": true, "seed": 60 }
  } }
```

| 字段 | 含义 |
|---|---|
| `at` | `[x, y]` 相对镜头矩形。**`y` 是她的脚底**，必须用母题自己的地面高度，否则她悬空 |
| `s` | 身高占画面高度的比例（这就是"景别"） |
| `facing` | `1` 向右、`-1` 向左、`0` 背影（不画脸，头发说话） |
| `pose` | `walk` `stand` `sit` `kneel` `crouch` `reach` `lookup` |
| `lamp` | 提灯。暗色段落给 `true`，暖色段落不必（房间已经亮了） |
| `seed` | 抖动种子。同一个人在不同镜头里头发摆动的相位不该一样 |
| `also` | 第二个人。配 `ghost: true` 就是"她记住的那个人" |
| `mirror` | 水面线的 `y`：她会在水下画出**自己的**倒影 |

## 骨架：姿态不是"把站姿压扁"

第一版把站姿的骨架乘一个系数就当成坐姿，结果**坐和跪看起来都是被压扁的人**——
一团，没有姿态。真实的原因是骨骼比例跟着姿态变：

```js
const BONES = {
  //        H     hip     sh    head    hr     hem    hair
  stand:  { H: 1.00, hip: 0.470, sh: 0.868, head: 0.938, hr: 0.060, hem: 0.300, hair: 0.500 },
  walk:   { H: 1.00, hip: 0.470, sh: 0.868, head: 0.938, hr: 0.060, hem: 0.330, hair: 0.500 },
  lookup: { H: 1.00, hip: 0.470, sh: 0.868, head: 0.938, hr: 0.060, hem: 0.300, hair: 0.530 },
  reach:  { H: 1.00, hip: 0.470, sh: 0.868, head: 0.938, hr: 0.060, hem: 0.300, hair: 0.500 },
  crouch: { H: 0.80, hip: 0.300, sh: 0.700, head: 0.872, hr: 0.079, hem: 0.130, hair: 0.440 },
  kneel:  { H: 0.72, hip: 0.235, sh: 0.650, head: 0.855, hr: 0.088, hem: 0.100, hair: 0.520 },
  sit:    { H: 0.56, hip: 0.115, sh: 0.605, head: 0.845, hr: 0.112, hem: 0.035, hair: 0.720 },
};
```

三个数最要紧：

- **`hip`**：坐着的人的髋部在**坐高的 0.115 处**（贴地），不是站高的 0.47。这是"坐"能读出来
  的唯一原因。
- **`hr`**：人矮下去之后头要**按比例变大**（0.060 → 0.112）。头不动、身体缩短，出来的是侏儒。
- **`hem`**：斗篷下摆离地多高。站姿停在胫骨（0.30），坐/跪必须**垂到地上**（0.035/0.100），
  不然布料把弯着的腿全埋了。

还有两个由姿态反推的尺寸：

```js
const hh = h;              // 这个姿态在屏幕上占多高（垂直基准）
const hw = h / B.H;        // "她本人多大"（水平基准）——肩宽、腿粗、头发都按它
```

`hw` 是为了让**宽度不随景别变**：坐姿的 `s` 比站姿小（人本来就矮），
如果肩宽也跟着 `hh` 缩，她就每坐一次瘦一圈。

## 剪影的两套取色

一个人要在暗页面和浅页面上都成立，只有一条规则：**身体是光的缺席**。

```js
const bodyOf = (pal) => light(pal) ? mixHex(pal.bg, pal.ink, 0.92)   // 浅底 → 用墨色压深
                                   : mixHex(pal.bg, '#000000', 0.60); // 暗底 → 比底色更暗
const rimOf  = (pal) => light(pal) ? pal.accent : ambient(pal);       // 背后那道光
```

- 暗页面：她比底色更暗（**不能**用 `pal.ink`——暗色主题的 `ink` 是接近白的亮色，
  画出来是一个洞），再沿一侧描一道 `ambient(pal)` 的背光边。
- 浅页面：用 `mixHex(bg, ink, 0.92)` 而不是纯黑，这样她还留在色板里。
- **邻居**（`ghost`）用 `mixHex(bg, ambient, 0.26)` / `mixHex(bg, ink, 0.34)`：
  由房间的颜色构成，不是由身体构成。

## 位置与景别

实测好用的取值带（85 刀全片验证过）：

| 景别 | `s` | 读作 |
|---|---|---|
| 大远景 | 0.10 – 0.16 | 她几乎是个点，环境在说话（收尾用） |
| 远景 | 0.22 – 0.28 | 她走在风景里 |
| 中景 | 0.30 – 0.38 | 主力景别 |
| 近景 | 0.40 – 0.46 | 情绪镜头（被刺到、伸手、坐下） |

- **相邻两刀不要同景别**。连着三刀 `0.36 / 0.38 / 0.40` 就是没有剪辑——一眼扫格子图就能
  看出来，所以镜头表里把 `s` 排成一行自己看：远景 → 中景 → 近景来回走，别连着写两个同值。
- **`x` 在一幕之内要连续漂移**。Act I 里她从 `0.70` 走到 `0.36`（八刀），
  观众读到的是"她在走"，而不是"每两秒换一张画"。这是"情节"最便宜的做法。
- `facing` 大半时间该是同一个方向（本片 61 右 / 17 背影 / 7 左），
  左边那几刀才有分量——`facing: -1` 是她**在回望**。

## 她占多宽（字幕要用这个数）

**这是加人物之后最先暴露的问题**：字幕在画面下方居中（`head` 槽，0.735H），
人物脚底在 0.88–0.92H，她一站过去，字就压在她腿上。要让字自动避开她，先得知道她有多宽。

宽度**不能按 `s` 估**。`figure.js` 里斗篷下摆画在 `hw * 0.185`，而 `hw = h / BONES[pose].H`，
所以坐姿（`BONES.H = 0.56`）实际占的画面宽度是 `s` 这个数字暗示的近 **1.8 倍**；
`sit` 伸出去的腿、`reach` 伸出去的手臂还要更宽。每个姿态一个半宽系数（单位：她的身高）：

```js
const POSE_HW = { stand: 0.20, walk: 0.20, lookup: 0.20, crouch: 0.24,
                  kneel: 0.27, reach: 0.27, sit: 0.37 };
const FIG_HW = (s, pose, W = 1920, H = 1080) => (POSE_HW[pose] ?? 0.20) * s * H / W;
```

有了它，`captionBox()` 就能算出字幕该放左边还是右边、盒宽多少，并把第二个人放到字幕的
反面（双人镜头把字夹在两具身体中间，那行字会窄到装不下一句话）。
完整机制见 **`references/subtitles.md`**。

别靠"把字幕再往下压"解决——脚底就在那儿。

## 编排：把镜头表写成幕

镜头表（`tools/shotlist.example.mjs`）里每一刀是
`{ t: 这一句唱到的秒数, zh: 字幕, m: 母题, p: 姿态, f: 朝向, s: 景别, x: 位置, g: 同框 }`。
让它像电影而不是像播放列表，靠四件事：

1. **一幕一个处境**。本片：独自走 → 风来了、有人并肩 → 那个人不见了 → 被回忆裹着走
   → 走出画面。同一批母题在四幕里回来，但她的状态不同，读起来就不同。
2. **姿态跟着歌词走**。`知れば知るだけ` 是"知道得越多越为难"→ 蹲下；`心の奥底に君が居る`
   → 跪下来把手放在心口；`世界に優しい風が吹いたら` → 抬头。
   姿态是**句子的动词**，不是随机分布。
3. **一次只让一个人多出来**。全片只有 12 刀是双人，集中在 bar 80–86 和 128–142
   （副歌的两次）。别的地方她都是一个人——所以那双 12 刀才有力量。
4. **收尾不要让她凭空消失**。最后一刀她 `s: 0.10`、`x: 0.86`，几乎出画，
   灯是全片最亮的东西。"走远"比"不见"更狠。

## 踩过的坑

| 症状 | 原因 | 修法 |
|---|---|---|
| 坐/跪是一团 | 站姿骨架乘系数 | 每个姿态一套骨骼比例（上表） |
| 她每近一次就瘦一圈 | 水平尺寸跟着屏幕高度走 | 引入 `hw = h / B.H` |
| 坐姿下摆把腿埋了 | 斗篷下摆高度写死 | `hem` 跟姿态走，坐/跪垂到地面 |
| 像一口钟 / 像企鹅 | 肩直接张到下摆，没有腰 | 路径中间收一次腰（`wWaist = wSh * 0.86`） |
| 暖色主题下一个惨白的鬼影 | `ghost` 用了"比底色亮"的取色 | 邻居要由**房间的颜色**构成，并再乘 0.5 透明度 |
| 人物被花/光晕吞掉 | 母题半径按 `r.w` 算，有人时没缩 | 母题读到 `b.figure` 就降尺度降到 0.58、对比减半 |
| 字幕压在腿上 | 人和字都在画面下部 | 用 `captionBox()` 按姿态算出字幕盒，双人镜头把他放到字幕反面 |
| 字幕印在膝盖上 | 按 `s` 估了她的宽度 | 坐姿实际宽度是 `s` 的 1.8 倍，用 `POSE_HW` 按姿态算 |
| 双人镜头那行字窄到换行 | 字被夹在两具身体中间 | 让 `also` 站在字幕的反面（见 `captionBox` 的 `gs`） |
| 门是纯黑的 | `mixHex` 返回了 `rgb()`，`hexA()` 只认十六进制 | `mixHex` 必须返回 hex |
| 倒影和她错开 | 另画了一个影子 | 倒影用 `figure.mirror`，由**同一个函数**翻转绘制 |
